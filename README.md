# INMO Card Lab

INMO Card Lab 是为 INMO Air2 智能眼镜开发的离线 21 点两副牌计数原型。它通过眼镜相机识别桌面上已出现的牌面，在本地维护 104 张牌的剩余数量，并实时显示下一张牌的概率分布。

## 0.1 功能

- CameraX 实时相机预览，固定使用 INMO Air2 的 Camera 0。
- 纯 Kotlin 牌角字形识别，兼容设备的 32 位 `armeabi-v7a` CPU。
- 两副牌共 104 张，追踪 A、2-10、J、Q、K 的剩余数量。
- 显示低牌 `2-6`、中性牌 `7-9`、十点牌 `10/J/Q/K` 与 A 的实时概率。
- 连续三帧确认、移开后重新上膛，降低重复记录风险。
- SQLite 本地会话记录，支持恢复、撤销和重新开局。
- 支持隐藏预览的省电显示，以及完全暂停相机。

## 安装

从 [Releases](../../releases) 下载 APK，然后通过 ADB 安装：

```bash
adb install -r INMO-Card-Lab-0.1-debug.apk
```

应用包名为 `com.jacb.inmocards`，最低支持 Android API 26，目标设备为 Android 9 的 INMO Air2。

## 使用

将扑克牌角的数字或字母放入黄色识别框，稳定约一秒。应用确认并记录后，先移开当前牌，再放入下一张牌。底部按钮可撤销记录、长按重开牌靴、切换省电显示或暂停相机。

## 限制

0.1 是本地原型，模板识别仍需按真实牌款、光照、距离和视角进一步校准。概率表示剩余牌组成，不是确定性结果预测。本版本尚不区分玩家手牌、庄家明牌或桌面座位。

完整开发约束和可复用需求提示见 [CORE_FEATURE_PROMPT.md](CORE_FEATURE_PROMPT.md)。
